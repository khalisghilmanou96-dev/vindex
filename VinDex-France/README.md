# VinDex France

Site statique inspiré du portail DexHub fourni.

- 231 appellations / dénominations viticoles référencées
- 14 grandes régions viticoles
- Recherche plein texte (nom, région, style, cépage)
- Filtres région + style
- Fiches en fenêtre modale
- Responsive mobile / tablette / desktop
- Aucun backend nécessaire

## Déploiement
Déposer `index.html` à la racine d'un hébergement statique (GitHub Pages, Netlify, Cloudflare Pages, FluxCast, etc.).

## Portée
Le site indexe des appellations et grandes dénominations, pas chaque domaine, château, cuvée ou millésime. La base est conçue pour être enrichie facilement dans la constante JavaScript `WINES`.
